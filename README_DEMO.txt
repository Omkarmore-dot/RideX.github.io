# RideX GitHub Pages Demo

This is a separate static demo generated from the uploaded RideX PHP/MySQL project.

IMPORTANT:
- The original PHP/MySQL project is NOT modified.
- GitHub Pages cannot execute PHP or MySQL.
- This demo is for PPT/viva presentation only.
- Booking, rental, courier and payment forms do not store or process real transactions.

## Deploy
1. Open the `RideX.github.io` GitHub repository.
2. Upload the CONTENTS of this folder to the repository ROOT.
3. Make sure `index.html` is directly in the repository root.
4. Keep GitHub Pages set to `main` and `/ (root)`.
5. Wait for deployment and open:
   https://omkarmore-dot.github.io/RideX.github.io/

Do not delete the existing original `RideX/` PHP project folder if you want to keep it as backup/source.
